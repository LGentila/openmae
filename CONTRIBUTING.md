# Contributing to OpenMaé

Thank you for your interest. Bug reports and ideas are welcome as
[issues](https://github.com/LGentila/openmae/issues).

## Pull requests

- Each pull request accepts the [Contributor License Agreement](CLA.md): tick its box in the pull request's
  description (the template holds it). A check stays red until it is ticked.
- Write code, comments, commit messages and pull request descriptions in English.
- Check that the app still builds (see "Building from source" in the [README](README.md)).
